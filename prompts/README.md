# Prompts

The prompts behind work on [skunkyard.com](https://skunkyard.com), as they were
given to Claude in Claude Code. Each file holds one prompt, with its revisions
folded in, and notes on what came out. Paste a prompt into Claude Code to try it
yourself.

| prompt | what it made |
|---|---|
| [`skunk-intro-video.md`](skunk-intro-video.md) | A 30-second animated video: a skunk types terminal commands you should never run |

## Format

Each file has a title, the facts about the run (date, tool, result), the prompt
in a quote block, and what came out. The prompt stays plain natural language,
exactly as it was typed, apart from fixed typos.
